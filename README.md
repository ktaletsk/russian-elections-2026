# russian-elections-2026

Воспроизведение анализа «Медузы»
[«Выборы в Госдуму-2026 — самые грязные парламентские выборы эпохи Путина»](https://meduza.io/feature/2026/09/24/vybory-v-gosdumu-2026-samye-gryaznye-parlamentskie-vybory-epohi-putina)
по сырым протоколам УИК, в виде [marimo](https://marimo.io)-ноутбука `notebook.py`.

## Данные

| Выборы | Источник |
|---|---|
| 2000–2024 | протоколы УИК из [dkobak/elections](https://github.com/dkobak/elections/tree/master/data) (сбор С. Шпилькина и И. Шукшина), скачиваются при первом запуске |
| 2026 | протоколы УИК из публичных сводных таблиц ЦИК через [neshodilina.netlify.app/api](https://neshodilina.netlify.app/api) |

`data/2026_federal.parquet` и `data/2026_meta.json` — замороженный снимок от 2026-09-23 18:40
(88 113 УИКов, из них 88 072 с данными). Кнопка в ноутбуке скачивает свежий снимок.
`data/integer_mc_cache.json` — кэш Монте-Карло (seed 42), чтобы не пересчитывать ~4 минуты.

## Что воспроизведено

* диаграммы «явка × результат ЕР» по УИКам, 2021 и 2026;
* положение «ядра» кометы для думских выборов 2003–2026;
* региональная картина: «московский столб», Петербург, Крым и Севастополь, Чечня; доля ДЭГ по регионам;
* плотность голосов на шести думских выборах;
* пики на целых процентах (гистограммы с шагом 0.1 п.п.);
* тест Кобака–Шпилькина–Пшеничникова на избыток «красивых» УИКов, 2000–2026.

Итоговая сверка с цифрами статьи — в конце ноутбука.

## Запуск

```bash
uvx --with pandas --with numpy --with matplotlib --with scipy --with requests --with pyarrow \
    marimo edit notebook.py
```
